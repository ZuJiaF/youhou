## Project Overview

This is a WPS AirScript (金山文档脚本) project that generates procurement sheets (采购表) and goods lists (货物清单) from a "功能表" data source.

## Architecture

- `生成货物清单.js` — main script, runs in WPS AirScript 2.0 environment
- The script reads data from "功能表", processes it, and writes to "采购表" + remote target workbook
- **货物清单 PDF** is generated by a remote backend cloud object (`wps/generatePdf`), NOT by the script itself
- The script sends `huoWuQingDanData` (column-oriented arrays) to the backend via `HTTP.post`, and receives a PDF download link

## Backend Integration

- Backend URL: `https://env-00jy671a213o.dev-hz.cloudbasefunction.cn/wps/generatePdf`
- Backend project: `聚树erp-支付宝云后端/uniCloud-alipay/cloudfunctions/wps/`
- PDF is generated with `pdfkit` + 思源黑体, uploaded to cloud storage, returns a temporary download URL

## Data Structure

- `huoWuQingDanData` is a column-oriented array: each element is one column, each column is an array of single-element arrays `[["value"]]`
  - `[0]` = title/ID, `[1]` = config type, `[2]` = header, `[3+]` = data rows
  - Columns: 品名, 款式, SKU, 数量, 装袋
  - Empty rows `[""]` are separators between product groups
  - Last row is `["总计:"]`

## Key Variables

- `arrayObj` — master field config (all columns from 功能表)
- `caigoubiaoArrayObj` — procurement sheet column config
- `huoWuQingDanArrayObj` — goods list column config (subset for PDF)
- `beiHuoData` — product stocking config with style codes and flags
- `caigoubiaoData` — processed procurement data (column-oriented)
- `huoWuQingDanData` — processed goods list data (column-oriented, derived from caigoubiaoData)

## Conventions

1. Column IDs (e.g., `ID001`, `ID018`) map to specific fields; look up via `getCol()`/`getRow()`.
2. Row ID `006` marks the totals row boundary in 功能表.
3. Use hash tags in comments for searchability (e.g., `#货物清单分支 #图片处理`).
4. The script environment provides `Application`, `ActiveWorkbook`, `HTTP`, `KSDrive`, `xlCenter`, `xlShiftUp`, `RGB()` etc. — these are WPS AirScript globals, not Node.js.
