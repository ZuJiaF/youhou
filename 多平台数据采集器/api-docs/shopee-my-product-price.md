# Shopee 马来站商品价格接口

## 实测范围

2026-10-06 用户回传的浏览器探测日志：马来站商品 `29377737789`，店铺 `323536941`。
这里只记录已观察到的响应字段，不含登录凭据。其他站点的币种和金额单位尚未实测。

## 基本信息

| 接口路径 | 商品节点 | 用途 |
| --- | --- | --- |
| `https://shopee.com.my/api/v4/pdp/get_pc` | `data.item` | 商品详情中的价格汇总与全部规格 |
| `https://shopee.com.my/api/v2/add_on_deal/get_main_item_info` | `data.item_details[]` | 主商品优惠数据，可补充同一商品的价格 |

两次实测响应状态都是 200。本次日志未记录请求方法、请求体、查询参数或认证头，采集器被动监听网页原有请求，不自行构造请求。

## 响应示例：仅列价格相关字段

```json
{
  "data": {
    "item": {
      "itemid": 29377737789,
      "currency": "MYR",
      "price": 874000,
      "price_min": 874000,
      "price_max": 2890000,
      "price_before_discount": 2000000,
      "price_min_before_discount": 2000000,
      "price_max_before_discount": 6000000,
      "models": [
        { "itemid": 29377737789, "price": 1990000, "price_before_discount": 5000000 },
        { "itemid": 29377737789, "price": 1590000, "price_before_discount": 4000000 }
      ]
    }
  }
}
```

示例规格仅列前两项；真实响应含 11 个规格。

| 字段 | 含义 | 实测结果 |
| --- | --- | --- |
| `itemid` | 商品编号，用于排除推荐商品或旧页面响应 | 与当前地址中的商品编号一致 |
| `currency` | 币种 | `MYR`，马来西亚林吉特 |
| `price_min` / `price_max` | 当前售价的最低与最高值 | `874000` / `2890000` |
| `models[].price` | 每个规格的当前售价 | 11 个有效价格，最低与最高与汇总一致 |
| `price*_before_discount` | 折扣前价格 | 单独记录，不参与当前售价区间 |

## 金额换算与校验

原始金额除以 **100000** 得到 MYR 金额：页面显示 `RM8.74`，详情数据为 `874000`，主商品优惠节点中的 `promotion_price` 同时显示 `RM 8.74`。

本商品售价区间为 **RM8.74–RM28.90**。全部规格原始售价依次为：

```json
[1990000, 1590000, 2842000, 890000, 1447000, 874000, 890000, 2890000, 874000, 1990000, 874000]
```

## 采集口径

- 优先读当前商品的 `price_min` / `price_max`；汇总缺失时，从完整的 `models[].price` 计算最低与最高值。
- 商品编号必须匹配；店铺编号存在时也必须匹配。未匹配的数据不进入预览和提交。
- 规格回退要求每个规格都有有效售价。空值、负值、非数字、上下限倒置时不生成区间。
- 不使用商品单一 `price` 冒充完整区间；相同上下限才显示单价。
- 不从推荐商品、运费补偿、店铺优惠券或划线价节点推导售价。
- 预览携带 `RM` 标识；保存至 `price_range`（每日价格区间字段）的值为 `8.74 - 28.90`，沿用现有 TikTok 字段格式。
- 这里只确认接口中的规格售价。店铺实际收款金额、用户额外优惠、运费等未在本次探测中确认。

## 其他响应

探测到 `/api/v4/pdp/hot_sales/get_item_cards` 返回推荐商品价格，`/api/v2/item/get_ratings` 返回评价；它们不作为当前商品的价格来源。
